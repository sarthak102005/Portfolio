## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sarthak102005/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Building for Production

```bash
# Linting
npm run lint

# Production build
npm run build
```
